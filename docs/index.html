Production-Grade Video Intelligence & Clipping Engine

ClippedAI is an autonomous, end-to-end pipeline that transforms long-form horizontal videos into viral 9:16 vertical clips. Powered by active speaker detection, camera motion stabilization, adaptive multi-speaker split layouts, word-synced kinetic typography, and complete multi-platform SEO packaging.

Fast-ASD (TalkNet + S3FD) Stationary Cluster Locking AssemblyAI Universal-2 Multi-Provider LLM Cascade PySceneDetect Hard Cuts Hormozi Neon Subtitles Deterministic Caching

01 The Real-World Creator Problem

Short-form video on YouTube Shorts, TikTok, and Instagram Reels is the single highest-leverage growth engine for creators. However, turning a 60-minute widescreen podcast into high-performing short clips remains a tedious 4-hour editing bottleneck.

⏱️
Manual Hook Hunting
Editors spend hours reading transcripts and scrub-timeline listening to spot self-contained conversational hooks with strong emotional retention.
🤢
Nauseating Camera Drift
Naive facial tracking causes continuous micro-panning and horizontal wobble that looks amateur and triggers immediate viewer swipe-aways.
👥
Multi-Speaker Banter
Interviews feature rapid banter. Simpler clippers crop one speaker randomly, missing the reaction of the listener or flipping erratically mid-word.

04 End-to-End Pipeline Architecture

Every video ingested passes through six deterministic processing stages engineered for speed and reliability:

01
Video Ingestion & Lightweight Audio Extraction
yt-dlp • FFmpeg
Accepts YouTube links or local video files. Automatically downloads up to 1080p source video into canonical cache, then extracts a lightweight 48kbps mono Opus/AAC audio track to minimize speech transcription payload size.
02
Sub-Word Diarization & 4-Tier Virality Cascade
AssemblyAI Universal-2 • Gemini 2.5 • Groq Llama 3.3
Transcribes speech with exact millisecond word timestamps and speaker labels. Evaluates psychological retention hooks (Curiosity Gap, Contrarian, Insight) scored out of 100 with optional target keyword focus, snapping cut boundaries to natural breath pauses (-0.2s / +0.3s).
03
Fast-ASD Lip-Sync & Diarization-Visual Fusion
PyTorch • TalkNet • S3FD Face Detector
Cross-attends mouth region bounding boxes with audio phonemes to track true active speakers. Fuses visual coordinates with diarization speaker IDs to prevent identity flipping during crosstalk and banter.
04
Stationary Cluster Locking & PySceneDetect Hard Cuts
signal_helpers.py • SciPy ndimage
Computes spatial coordinate clusters. If movement is below the stationary threshold (σ < 0.06), coordinates are locked to cluster medians, eliminating camera micro-drift. Enforces instant snap-cuts on scene transitions via ContentDetector(threshold=27.0).
05
Adaptive Split Compositing & Seam-Anchored Subtitles
OpenCV • Libass • PIL Typography
Renders single portrait crops or stacked 2/3/4 speaker panels with 2D AR-safe headroom scaling. Compiles word-level animated karaoke subtitles (.ass) anchored dynamically to the central seam (\an5\pos(540,960)) in split mode so text never covers faces.
06
Creator Distribution Pack & Isolated Storage
cli.py • export_pack.py
Saves vertical MP4 clips cleanly in root folder clips/<Title>/clip_X.mp4. Generates centered portrait hook thumbnails and multi-platform SEO packages (YouTube Shorts, TikTok, Instagram Reels) cleanly isolated into assets/.

05 Deep Dive: Solved Engineering Challenges

Production video processing requires solving fundamental computer vision and audio-visual synchronization edge cases:

1. Stationary Cluster Locking (The Camera Jitter Problem)

Face detector bounding boxes fluctuate by ~0.02–0.06 in normalized coordinates every frame even for a seated speaker. In signal_helpers.py, we analyze spatial coordinate clusters with gap analysis (CLUSTER_GAP = 0.04). When standard deviation is below 0.06, we freeze the camera coordinates to the median. Gaussian temporal filtering (σ = 12) is decoupled and applies only when a speaker genuinely walks across the scene (σ ≥ 0.06).

backend/src/signal_helpers.py

largest_cluster = max(clusters, key=len)
is_stationary = float(np.std(largest_cluster)) < STATIONARY_STD_THRESHOLD

2. 2D AR-Safe Headroom Normalization (The Aspect Ratio Problem)

Cropping horizontal footage into vertical 9:16 split panels (1080×960) often introduces severe geometric distortion. In video_processing.py, every cell uses an identical crop width (608px) and height (541px), guaranteeing identical 1.776× scale factors across both axes with vertical eye-line headroom fixed at $cy = 0.42$.

backend/src/video_processing.py
# AR-Safe universal crop dimensions (1080p source)
CROP_W_1 = 608   # universal 9:16 crop width for every layout cell
CROP_H_HALF = int(round(CROP_W_1 * (OUT_H // 2) / OUT_W))  # = 541px
# Scale factor difference between horiz (1.776x) and vert (1.774x) is <0.1%

06 Installation & Local Setup Guide

ClippedAI runs locally on macOS (optimized for Apple Silicon MPS) or Linux (CPU/CUDA):

Terminal — Environment Setup
# 1. Clone the repository
git clone https://github.com/ETS2K7/clipped-ai.git
cd clipped-ai

# 2. Setup Virtual Environment
python3 -m venv venv
source venv/bin/activate

# 3. Install Core Dependencies (PyTorch, Fast-ASD, OpenCV, Libass)
pip install -r backend/requirements.txt

# 4. Configure API Keys
cp .env.example backend/.env
# Add ASSEMBLYAI_KEY and optional GEMINI_API_KEY / GROQ_KEY in backend/.env
