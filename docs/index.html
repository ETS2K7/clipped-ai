The Problem

The short-form editing bottleneck.

Short-form vertical video is the dominant growth channel for creators, but converting horizontal podcasts into short clips is a grueling 4-hour manual process.

⏱

Manual Hook Hunting.

Editors spend hours scanning transcripts to find self-contained conversational hooks with strong retention potential.

🤢

Nauseating Camera Drift.

Naive facial tracking causes continuous micro-panning and horizontal wobble that triggers viewer drop-off.

👥

Multi-Speaker Chaos.

Traditional tools crop one person at random, cutting out listener reactions or flipping erratically mid-word during banter.

System Differentiation

Why ClippedAI is fundamentally different.

Most hackathon projects perform simple center crops and basic Whisper captions. ClippedAI is engineered as an end-to-end computer vision and speech intelligence engine.

System Architecture

The 6-stage clipping pipeline.

Every video ingested passes through six deterministic processing stages engineered for speed and reliability.

01

Video Ingestion & Lightweight Audio Extraction.

Downloads up to 1080p source video via yt-dlp, then extracts a lightweight 48kbps mono Opus/AAC audio track to minimize speech transcription payload size.

yt-dlp • FFmpeg
02

Sub-Word Diarization & 4-Tier Virality Cascade.

Transcribes speech with exact millisecond word timestamps. Evaluates psychological retention hooks (Curiosity Gap, Contrarian, Insight) scored out of 100 with breath pause snapping.

AssemblyAI • Gemini • Groq
03

Fast-ASD Lip-Sync & Diarization-Visual Fusion.

Cross-attends mouth region bounding boxes with audio phonemes to track active speakers, fusing coordinates with diarization speaker IDs to eliminate crosstalk flips.

PyTorch • TalkNet • S3FD
04

Stationary Cluster Locking & Hard Cuts.

Computes spatial clusters. If movement is below threshold (σ < 0.06), coordinates lock to cluster medians. Enforces instant snap-cuts on scene transitions.

signal_helpers.py • SciPy
05

Adaptive Split Compositing & Subtitles.

Renders single portrait crops or stacked 2/3/4 speaker panels with AR-safe scaling. Compiles kinetic karaoke subtitles (.ass) anchored dynamically to the central seam in split mode.

OpenCV • Libass • Pillow
06

Creator Distribution Pack & Isolated Storage.

Saves vertical MP4 clips in root folder clips/<Title>/clip_X.mp4. Generates centered hook thumbnails and multi-platform SEO packages cleanly isolated into assets/.

cli.py • export_pack.py
Engineering Deep Dive

Solved hard problems.

Production video processing requires solving fundamental computer vision and audio-visual synchronization edge cases.

Stationary Cluster Locking.

Face bounding boxes naturally jitter by 0.02–0.06 normalized coordinates every frame. Spatial gap analysis clusters positions; when σ < 0.06, camera coordinates lock to the median with 0.0px micro-jitter.

backend/src/signal_helpers.py
largest_cluster = max(clusters, key=len)
is_stationary = float(np.std(largest_cluster)) < 0.06

if is_stationary:
    # Locked Mode: Assign frames to cluster center
    cluster_centers = [float(np.median(c)) for c in clusters]

2D AR-Safe Headroom Normalization.

Cropping horizontal video into vertical 9:16 split panels (1080×960) typically causes severe distortion. Equal 608×541 source crops guarantee identical 1.776× scaling on both axes with natural $cy = 0.42$ headroom.

backend/src/video_processing.py
# AR-Safe universal crop dimensions (1080p source)
CROP_W_1 = 608   # universal 9:16 crop width
CROP_H_HALF = int(round(CROP_W_1 * (OUT_H // 2) / OUT_W))  # = 541px

Quickstart

Local installation & execution.

Run ClippedAI locally on macOS (Apple Silicon MPS) or Linux (CPU/CUDA).

Terminal — Setup & Execution
# 1. Clone repository
git clone https://github.com/ETS2K7/clipped-ai.git
cd clipped-ai

# 2. Setup Virtual Environment
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt

# 3. Configure API Keys
cp .env.example backend/.env

# 4. Run Interactive Pipeline CLI
./cli.py
